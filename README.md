# TBM Player – נגן IPTV לאנדרואיד ולאנדרואיד TV

## מה יש באפליקציה
- **רשימות:** M3U (קישור או קובץ מהמכשיר) ו-Xtream Codes. קישור `get.php?username=…&password=…` מומר אוטומטית ל-Xtream.
- **ממשק בסגנון MyTVOnline:** תפריט צד, עמודת קטגוריות, רשימת ערוצים ותצוגה מקדימה חיה עם לוח שידורים (EPG – כרגע ב-Xtream בלבד). בטלפון במצב לאורך – קטגוריות כשורת צ'יפים.
- **סינון:** לפי ארצות (זיהוי אוטומטי מקידומת הקבוצה – IL, UK, |FR| וכו') ולפי קבוצות, בנפרד לערוצים / סרטים / סדרות. הסתרת תוכן למבוגרים.
- **סדרות:** עונות, פרקים, התקדמות צפייה, מעבר אוטומטי לפרק הבא.
- **מועדפים** (לחיצה ארוכה), **המשך צפייה** מהנקודה שעצרת, **חיפוש** כללי.
- **נגן:** ExoPlayer עם מפענח FFmpeg (AC3/EAC3/DTS), HLS ו-TS, בחירת אודיו/כתוביות/מהירות, יחס תצוגה, תמונה-בתוך-תמונה, החלפת ערוץ בחצים/Channel ±, ניסיון התחברות מחדש בערוצים חיים, נגן חיצוני כאפשרות.
- **כתוביות אוטומטיות:** חיפוש מקבילי ב-Wizdom, כתובית (Ktuvit), OpenSubtitles ו-SubDL, לפי סדר שפות (ברירת מחדל: עברית ואז אנגלית). טעינה אוטומטית של הטובה ביותר, רשימה לבחירה ידנית, סנכרון ±0.5 שנ׳, תיקון קידוד עברי (windows-1255) ותיקון פיסוק RTL.

## כתוביות – מה צריך להגדיר
| אתר | שפה | מה צריך |
|---|---|---|
| Wizdom | עברית | כלום |
| כתובית (Ktuvit) | עברית | אימייל + סיסמה מוצפנת (הסבר במסך ההגדרות) |
| OpenSubtitles | הכל | מפתח API חינמי מ-opensubtitles.com |
| SubDL | הכל | מפתח API חינמי מ-subdl.com |

## בניית APK דרך GitHub (בלי להתקין כלום)
1. היכנס ל-github.com ← New repository ← שם: `TBMPlayer` ← Private ← Create.
2. בעמוד הריפו: **uploading an existing file** ← גרור את **כל התוכן** של התיקייה (כולל התיקייה `.github`) ← Commit.
   - אם התיקייה `.github` לא עלתה בגרירה: Add file ← Create new file ← בשם כתוב `.github/workflows/build.yml` והדבק את התוכן מהקובץ.
3. לשונית **Actions** ← הבנייה תרוץ (5–8 דקות). כשמופיע ✓ ירוק – לחץ על הריצה ← למטה **Artifacts** ← `TBMPlayer-apk`.
4. חלץ את ה-ZIP, העבר את ה-APK לטלפון/טלוויזיה והתקן (לאשר "התקנה ממקורות לא ידועים").
   - לטלוויזיה: הכי נוח עם האפליקציה Downloader או Send Files to TV.

אם הבנייה נכשלת – שלח לי את הודעת השגיאה מלשונית Actions ואתקן.
