# TBM Player 2.0 – נגן IPTV לאנדרואיד ולאנדרואיד TV

## תכונות
**ממשק**
- דף בית בסגנון MyTVOnline: ערוצים אחרונים, המשך צפייה (סרטים/סדרות), פופולרי היום (TMDB), נוספו לאחרונה
- טלפון: סרגל ניווט תחתון. טלוויזיה/טאבלט: תפריט צד + תצוגה מקדימה חיה עם לוח שידורים
- עברית / English (הגדרות ← שפת אפליקציה), תמיכה מלאה בשלט

**תוכן**
- M3U (קישור/קובץ) ו-Xtream Codes, תוקף מנוי ועדכון אחרון, רענון אוטומטי (6/12/24/72 שעות)
- ניהול קבוצות: נעיצה, סדר, הסתרה, סינון לפי ארצות
- ניהול ערוצים (לחיצה ארוכה): מועדפים, שינוי שם, סדר, הסתרה, נעילה, אישור לילדים, הקלטה
- סדרות: עונות, פרקים, "המשך S01E04", מעבר אוטומטי לפרק הבא

**לוח שידורים וצפייה לאחור**
- EPG מלא מ-XMLTV (Xtream אוטומטי, url-tvg, או כתובת ידנית, כולל ‎.gz)
- Catch-up: צפייה בתוכניות מהשבוע האחרון (Xtream timeshift, catchup של M3U)
- תזכורות לתוכניות + הקלטות מתוזמנות

**נגן**
- ExoPlayer + FFmpeg (AC3/EAC3/DTS), HLS/TS, In-App PiP + System PiP, Chromecast
- רשימת ערוצים בתוך הנגן, זפזופ במספרים, ערוץ קודם, טיימר שינה, יחס תצוגה
- הקלטה (TS/HLS) לזיכרון המכשיר, Multi-view של 4 ערוצים

**כתוביות בעברית מכל מקום**
- Wizdom, כתובית, OpenSubtitles, SubDL, SubSource, Podnapisi, YIFY – חיפוש מקבילי
- אם אין עברית: הצעה לתרגום מכונה (Google) של הכתובית האנגלית, מוצג RTL
- טעינה אוטומטית, זיכרון לכל פרק, סנכרון ±0.5 שנ׳, תיקון קידוד ופיסוק עברי

**בקרת הורים ופרופילים**
- פרופיל מבוגר (תוכן מלא) ופרופילי ילדים (רק מה שאישרת), "מי צופה?" בפתיחה
- קוד הורים + טביעת אצבע, נעילת קטגוריות מבוגרים/קבוצות/ערוצים, נעילת הגדרות, ניקוי היסטוריה ביציאה
- גיבוי ושחזור לקובץ, איפוס העדפות

## מפתחות חינמיים (לא חובה)
| שירות | למה | איפה |
|---|---|---|
| OpenSubtitles | כתוביות | opensubtitles.com → Profile → API consumers |
| SubDL | כתוביות | subdl.com → Account → API Key |
| SubSource | כתוביות | subsource.net → API |
| כתובית | כתוביות בעברית | אימייל + סיסמה מוצפנת (הסבר בהגדרות) |
| TMDB | פופולרי היום | themoviedb.org → Settings → API |

## בניית APK
**Android Studio:** File ← Open ← התיקייה ← Build ← Build APK(s).

**GitHub (בלי להתקין כלום):**
1. github.com ← New repository (Private).
2. העלה את כל תוכן התיקייה, כולל `.github`.
3. Actions ← אחרי ✓ ירוק ← Artifacts ← `TBMPlayer-apk`.
4. העבר את ה-APK לטלפון/טלוויזיה והתקן.

אם הבנייה נכשלת – שלח את הודעת השגיאה ואתקן.
